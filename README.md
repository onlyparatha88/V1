# OnlyParatha — Bulk Flatbread Sourcing Website

A website for **OnlyParatha**, a sourcing intermediary connecting certified paratha manufacturers with bulk foodservice buyers.

## Model
- Zero-inventory middleman
- Manufacturer fulfils and ships under their own brand
- OnlyParatha facilitates the connection

## Minimum Order
- 200–300 Parathas per slot
